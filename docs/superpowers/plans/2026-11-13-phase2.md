# Phase 2 — Real Work, Blog & Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the portfolio into a server-backed Next.js app that shows Hassan's real work (no demos), adds a public blog, and a protected admin for writing it — then finish the remaining site sections, case studies, translations and verification.

**Architecture:**
- Next.js 16 runs on Node (`next start`); public marketing pages stay statically generated.
- The blog and admin render dynamically.
- Postgres (Supabase project `personal` in production; PGlite in tests) is reached only from the server via Drizzle.
- Media goes through a server upload route into Supabase Storage (local-disk driver in tests).
- Custom username/password admin auth uses argon2id and database sessions.

**Tech Stack:**
- Next.js 16.4, React 19, TypeScript strict, Tailwind 4.3, motion 14
- drizzle-orm 0.45 + drizzle-kit, `postgres` (postgres.js)
- `@electric-sql/pglite` 0.5 + `@electric-sql/pglite-socket` 0.2 (tests)
- `@node-rs/argon2` 2.2, zod
- unified + remark-parse + remark-gfm + remark-rehype + rehype-slug + rehype-sanitize + @shikijs/rehype + rehype-stringify
- `@supabase/supabase-js` (server-only, storage)
- Vitest, Playwright 1.65, @axe-core/playwright

## Global Constraints

- Every phase-1 Global Constraint still binds (claims, operations ≠ engineering, AI vs deterministic, preliminary assessment, MG Mobile not released, Crew-MG security wording, contacts, a11y WCAG 2.2 AA, reduced motion, logical CSS, no overflow 320–1440 in every locale, colours, fonts, Latin digits) — except the "Illustrative demo · sample data" rule, which is replaced by **no demo or sample data anywhere**.
- **Muscle Generator** is removed from content, UI, tests and translations.
- **Real URLs only:**
  - Calculator `https://visa-file-strength-calculator.vercel.app`
  - Consultation `https://consultatioin.vercel.app`
  - QR Studio `https://queue-r-code.vercel.app`
  - Review has no public URL. Never invent URLs.
- **Embed status (2026-11-13):** Calculator `blocked-by-site`, Consultation `blocked-by-site`, Review `no-public-url`, QR Studio `allowed`.
- **Honest fallback copy:** "This site's security settings don't allow it to be shown inside another page." plus an **"Open website"** link (target _blank, rel noopener noreferrer).
- **Secrets:**
  - Server-only env: `DATABASE_URL`, `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `ADMIN_USERNAME`, `ADMIN_INITIAL_PASSWORD`, `STORAGE_DRIVER` (`supabase` | `local`), `LOCAL_STORAGE_DIR`.
  - No `NEXT_PUBLIC_*` secrets.
  - `.env.example` holds placeholders only.
  - Never log or commit the admin password.
- **Session cookie:** `__Host-hp_session` (HttpOnly, Secure except on `http://localhost` in development/test, SameSite=Strict, Path=/), 7-day sliding expiry; the token is stored as sha256 in `admin_sessions.id`.
- **Login lockout:** 5 failed attempts per (lower(username), ip) per 15 minutes, then locked until the window ends. One generic error message: "Invalid username or password."
- **Every admin page, server action and route handler** calls `requireAdmin()` server-side. `proxy.ts` is a convenience redirect only.
- **Upload:**
  - JPEG/PNG/WebP/AVIF only, verified by magic bytes; ≤ 5 MB.
  - Stored path `blog/<uuid>.<ext>`; never the client filename.
  - The route checks `Origin` equals the request host.
- **Markdown:** sanitized with rehype-sanitize (default schema + `className` on `code`/`span` for Shiki + `id` on headings). No raw HTML, no `javascript:` URLs.
- **Slugs:** `^[a-z0-9]+(?:-[a-z0-9]+)*$`, max 80, unique per locale.
- **Reading time:** `ceil(words / 200)` minutes, minimum 1.
- **TOC:** shown when an article has ≥ 3 h2/h3 headings.
- **Drafts** never appear in public pages, listing, search, sitemap or OG.
- **Admin UI:** English, `noindex`, not localized. Article content fields use `dir="auto"`.
- **Blog visual direction** (from seifashraf.tech/blog, adapted to Hassan's identity, nothing copied):
  - Single narrow reading column.
  - Posts as full-width rows (meta line "date · N min read · tags" in small mono, bold title, short excerpt). An optional small cover thumbnail sits on the end side.
  - Large page title with a one-line subtitle.
- **Tests never touch the production database.**

## Review Focus

1. **Draft leakage:**
   - A draft slug requested directly, via search query, tag filter, sitemap or OG route must 404 or be absent.
   - Pinned in Task 21 (`drafts are invisible everywhere`).
2. **Session/auth bypass:**
   - Calling a server action or the upload route without a cookie, with an expired session, or with a cross-origin `Origin` must be rejected.
   - Pinned in Tasks 16, 18, 19.
3. **Malicious Markdown:**
   - `<script>`, `<img onerror>`, `[x](javascript:alert(1))` and an inline `<iframe>` in content must render inert.
   - Pinned in Task 17 (unit) and Task 20 (e2e preview + public page).
4. **Arabic article version:**
   - RTL content with Latin code blocks must render with `dir="rtl"` on the article and `dir="ltr"` on `pre`.
   - Pinned in Task 20.
5. **Site down or headers change:**
   - QR Studio failing must keep the poster + "Open website".
   - Screenshots missing must show the text presentation, never a blank frame.
   - Pinned in Task 14.
