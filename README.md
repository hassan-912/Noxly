# Hassan Azab portfolio

Statically exported Next.js site (en, de, fr, ar).

## Run
- `npm run dev` — dev server
- `npm run build` — checks `site.url`, then exports to `out/`

## Test
- `npm test` — unit tests (vitest)
- `npm run test:e2e` — Playwright against `npx serve out -l 4173` (run `npm run build` first)

## Launch blockers
- Real domain (`site.url` is the placeholder `https://azab.dev`)
- Native-speaker translation review (de, fr, ar)
- Portrait photo
- Femine-EG, Voclio and Treasure Hunt links
